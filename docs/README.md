# Hypertext Exporter — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning, doing, looking up and understanding are four different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first page.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Turn a folder of three notes into one HTML page. |
| **[Write a recipe](how-to/write-a-recipe.md)** | Task-oriented. Name and order groups, add overview tables, fold the entry note, include other folders. |
| **[Export from the command line](how-to/export-from-the-command-line.md)** | Task-oriented. Start an export from a script and read the result. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. Every notice and error the plugin shows, with cause and fix. |
| **[Recipe reference](reference/recipe.md)** | Information-oriented. Every key, its German alias, default and state in this version. |
| **[Findings reference](reference/findings.md)** | Information-oriented. Every finding code with severity and meaning. |
| **[Security and determinism](explanation/security-and-determinism.md)** | Understanding-oriented. What the page protects against, what it does not, and why the same notes give the same bytes. |

The [README](https://github.com/johannes-kaindl/hypertext-exporter/blob/main/README.md) covers what the plugin does, how to install it and every setting.
